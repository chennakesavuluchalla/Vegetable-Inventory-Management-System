# Vegetable-Inventory-Management-System
A Python-based, menu-driven Vegetable Inventory Management System developed to simplify the daily operations of a vegetable store. The system provides separate Owner and User modules, allowing efficient inventory management, customer shopping, billing, and sales tracking. It is built using Python dictionaries, functions, loops, and file handling concepts.

📌 Features

-👨‍💼 Owner Module
- Add vegetables to inventory
- Update item details (price, quantity, etc.)
- Remove items from inventory
- View available inventory
- View customer details
- Generate sales reports
- Calculate total revenue and profit

👤 User Module
- Browse available vegetables
- Add items to cart
- Modify cart
- Remove items from cart
- View cart
- Generate billing receipt
